БАЗИСДОМ — ИСХОДНИКИ ПРОТОТИПА КОММЕРЦИИ
Актуальная версия от 24.11.2026, включая кружки цвета линии метро.

СТРАНИЦЫ
index.html — поиск и каталог коммерческих объектов.
bc.html?id=noon — карточка НУН, основная компоновка.
bc.html?id=tech — карточка Технопарка.
bc-new.html?id=noon — сохранённая альтернативная компоновка.
bc-new.html?id=tech — альтернативная компоновка Технопарка.

ОБЩИЕ ФАЙЛЫ
styles.css — основные стили и адаптивность.
original-card.css — стили основной карточки объекта.
app.js — отображение страниц и взаимодействия.
data.js — данные объектов, предложения, станции метро и цвета линий.
engine.js — фильтрация и сортировка.
assets/ — изображения, логотип и шрифт.

ЗАПУСК
Распакуйте весь архив, сохранив структуру папок.
Откройте index.html в браузере.
Для локального HTTP-просмотра из этой папки: python3 -m http.server 8000
Затем откройте http://localhost:8000/
Сборка и установка npm-зависимостей не требуются.

В прототипе карта схематическая, заявка демонстрационная и никуда не отправляется.
Для переноса на рабочий сайт используются существующие карта и механизм заявок.
Дополнения для раздела «Новостройки» описаны в ТЗ; этот архив содержит
код текущего прототипа коммерции.
